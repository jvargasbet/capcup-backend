# CapCup Frontend

Editor de video en React + Vite + TypeScript: sube un video, lo transcribe con el backend y muestra los subtitulos en un timeline clickeable, ademas de un overlay de subtitulos estilo CapCut (mayusculas, negrita, resaltado palabra por palabra) sobre el video.

## Setup

```bash
npm install
cp .env.example .env   # ajusta VITE_API_BASE_URL si el backend no corre en localhost:8000
npm run dev
```

## Tests

```bash
npm run test
```

## Build

```bash
npm run build
```
